# Jai-Vulkan

This repo contains code generated from Vulkan headers version 1.4.357.0.
It's based on the code present in the Modules that come with Jai, so they come with the same warnings.

## Contributing

To regenerate the bindings, first make sure the [Vulkan SDK](https://vulkan.lunarg.com/sdk/home) is installed on your system.
Then run :

```
jai generate.jai
```
